# Valhalla Freight v0.4.1 — Customer 360 Usability

## Changes
- Dedicated Notes tab separate from Activity.
- Larger note composer and larger readable note cards.
- Google Places address autocomplete component for customer locations.
- City, state, postal code and country populate from a selected address.
- Manual location entry remains available when Google Maps is not configured.
- US phone numbers format as `(913) 223-4045` in customer and contact forms.
- Contact email/phone links remain directly actionable.
- Customer profile website, billing email and main phone are directly actionable.
- Customer code is now generated server-side using `VFC-000001` format.
- Customer modal no longer asks users to invent a customer code.

## Google Places configuration
Add `VITE_GOOGLE_MAPS_API_KEY` to your local `.env` file. The key should be configured in Google Maps Platform for Maps JavaScript API and Places API and restricted for the domains that serve Valhalla Freight.

The address component lives at `frontend/src/features/customers/components/AddressAutocomplete.tsx` so it can later be reused by Quote Studio, shipper/consignee forms and billing addresses without duplicating Google Maps logic.
