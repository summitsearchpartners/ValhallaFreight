# Valhalla Freight v0.5.1 — Quote-to-Shipment Workflow

This release converts Quote Studio from a rate-only screen into an operational workflow.

## Quote lifecycle

1. Rate a shipment in Quote Studio.
2. Select a normalized carrier option.
3. The quote is saved with `selected` status and appears in Quote Bucket.
4. Open the quote record to review lane, freight, all carrier options, selected rate, GP, and expiration.
5. Approve the selected rate and optionally set pickup date.
6. Valhalla Freight creates the shipment and marks the quote `booked`.
7. The new shipment opens in Shipment Control Tower.

## Direct shipment creation

Shipment Control Tower > Create Shipment supports known-carrier bookings. Users select the customer, carrier, origin/destination, freight details and pickup date. Valhalla Freight rates the selected carrier, creates a quote audit record, then immediately creates the operational shipment.

## Routing fixes

Command Center quote-savings drill-down links now open the actual quote record instead of an empty Quote Studio.
