# Valhalla Freight v0.7.4 - Shipment BOL Details

## Purpose
Capture shipment-level reference and commodity information after booking so operations can complete the Bill of Lading without rebuilding or re-rating the quote.

## Editable shipment fields
- PO number
- Customer reference
- Package count
- Package type
- Commodity description
- NMFC number
- Hazmat emergency contact
- Hazmat emergency phone
- Declared value
- BOL and PRO numbers
- Existing operational schedule/actual timestamps

## BOL automation
All shipments created from a quote approval or direct booking receive a `VFBOL-...` number at creation. The professional BOL pulls the shipment fields above automatically.

## Database upgrade
`schema_updates.py` adds the new nullable shipment columns idempotently so existing local data is preserved.
