# Valhalla Freight v0.4.3 — Customer 360 Readability

Customer detail workspaces now use the available browser width instead of the global 1540px content cap. Typography, KPI cards, tabs, account fields, contact details, billing address, shipment rows, location cards, contact cards, commercial controls, and activity text were enlarged for desktop readability.

The wide-layout behavior is route-scoped to `/customers/:customerId`, so other Valhalla Freight modules retain their existing layout until intentionally upgraded.
