# v0.12.2 — Carrier 360 Rate Availability & Direct Service Controls

- Carrier 360 now supports rate controls at the carrier-wide or lane level.
- Controls can suppress rates indefinitely or within a start/end window.
- Lane matching accepts origin/destination city, state, ZIP, or ZIP prefix.
- Direct-only controls require a live carrier API to verify direct service; unverified simulated rates fail closed.
- Dayton Freight passes `directOnly=true` to its live Rates API when a matching direct-only rule applies.
- Existing carrier Active/Inactive remains the master indefinite network switch.
