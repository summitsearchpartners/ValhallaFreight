# Valhalla Freight v0.3.0 — Authenticated Application Shell

This release establishes the shared operating shell for the authenticated Valhalla Freight TMS.

## Included
- Collapsible Valhalla Freight navigation rail
- Operations, Network and Intelligence navigation groups
- Functional Ctrl+K global command/search palette
- Notification center dropdown with unread state
- User/profile menu with role display and sign-out
- Live operations status indicator
- Responsive desktop/mobile shell behavior
- Product version indicator
- Existing protected application routes preserved

The command palette is intentionally navigation-first in v0.3.0. As shipment, customer, quote and carrier search endpoints mature, the same surface can be connected to live entity search without redesigning the shell.
