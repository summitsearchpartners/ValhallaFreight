# Valhalla Freight v0.2.2 — Full Product Rename

This release removes the former product name from the active source tree and standardizes the application on **Valhalla Freight**.

## Renamed
- User-facing product copy and intelligence labels
- PostgreSQL database, user, password, and Docker volume identifiers
- Backend default database URL
- Environment example database URL
- Startup/reset script set (Valhalla Freight only)

## Local database reset required
Because the Docker/PostgreSQL identifiers are now `valhalla_freight`, upgrading from the prior local development build creates a new Valhalla Freight database volume. The prior development database only contained seed/test data, so v0.2.2 intentionally starts with a clean local database and reseeds the development administrator.
