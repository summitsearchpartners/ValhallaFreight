# v0.19.1 — Truckload entry improvements

Copy the contents of this project over your existing project. Keep your existing .env. From a separate PowerShell window:

```powershell
Set-Location C:\GitHub\ValhallaFreight
docker compose -p valhallafreight up -d --build
```

Open http://localhost:5173 and press Ctrl+F5.

## Changes
- Redesigned truckload popup with customer/freight, route and dispatch sections, optional contact fields, responsive layout and one sticky save action.
- State dropdowns prevent long-name errors. The server also accepts full US state names and converts them to postal abbreviations, including saved locations.
- Blank new-load weight and package inputs avoid accidental default totals.
- Errors identify pickup/delivery and field, display inline, and provide clickable summary links. Your entries remain available for correction.
- Saved customer facilities automatically fill address, facility, contact, phone and instructions.
- Google street suggestions fill city, state and ZIP when configured. All addresses remain editable.

## Google autocomplete setup
Saved facilities work without any Google key. New-address autocomplete requires your own Google Cloud key with billing, Maps JavaScript API and Places API (New) enabled. Restrict the key to your actual HTTP origins, such as http://localhost:5173/*, and those APIs.

Add to the existing root .env (do not overwrite its other secrets):

```
VITE_GOOGLE_MAPS_API_KEY=your_key_here
```

Run the Docker command above and refresh. Select an actual suggestion to populate city/state/ZIP; typing alone does not confirm a result. If Google is unavailable, enter the address manually. No live Google request was tested because no customer key was supplied.

## Data compatibility
No migration or volume name changes. Existing PostgreSQL data, document storage, Safe Load mobile project, manufacturer financial privacy and broker functions are retained. Never remove your database volume. This ZIP contains project source; it does not contain your desktop PostgreSQL backup.
