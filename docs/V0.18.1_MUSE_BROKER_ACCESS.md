# v0.18.1 — Muse company Broker Admin access

## What changed

- A company's **Broker Admin** accounts gain Muse Portal access only when Super Admin designates that company as the Muse Freight partner.
- Other Broker Admins and regular Brokers do not gain Muse access.
- Muse's Broker Admins keep their normal broker workspace and see **Administration → Muse Portal**. Open that link, then **Manufacturers** to see the manufacturers opted in by Super Admin, including applications not yet submitted.
- The ordinary broker **Customers** list remains scoped to its own customers. Opted-in manufacturers from other companies are listed in the **Muse Portal → Manufacturers** workspace.
- Customer Portal in Administration, its search result, its page, and its dedicated administration APIs are now Super Admin only. Actual Customer accounts can still use their own customer portal.
- Muse manufacturer opt-in and the Muse partner-company designation remain Super Admin only.
- Applications, Muse review and approval, rate entry, shipment/BOL creation and booking confirmation remain intact.

## Configure your existing Muse Broker Admin

1. Update the source in your existing Compose project and rebuild:
   ```sh
   docker compose up -d --build
   ```
2. As Super Admin, open **Users & Company Access** and expand **Muse Freight partner access** above the account totals.
3. Set **Muse Freight company** to the company assigned to your existing Muse **Broker Admin** login, then save.
4. Refresh the Muse Broker Admin's browser or sign out and back in.
5. Open **Administration → Muse Portal → Manufacturers**. A manufacturer must also have **Customers → manufacturer → Commercial → Offer Muse Freight rates to this manufacturer** enabled by Super Admin.

For upgrades, if there is exactly one parent company named “Muse Freight” with an existing Broker Admin or legacy Muse Freight Admin account, the first startup designates it automatically. If none or multiple match, no company is granted automatically; use the selector above. Once initialized, later company name or logo changes never change the designation. Setting “No partner company assigned” revokes partner-company access. Server authorization checks every request, even when a session's menu has not refreshed yet.

Legacy dedicated Muse Freight Admin logins are retained for compatibility, but must belong to the same designated Muse partner company to access the portal. Use **Broker Admin** for the existing Muse brokerage account.

## Data and checks

The existing Compose volume definitions and migration script are unchanged. A new additive singleton table stores the partner company ID. No account passwords, company ownership, quotes, applications, shipments, or document data are rewritten.

API checks cover company-specific access, denied access for other brokers, revocation with existing tokens, unchanged brokerage isolation, and Super Admin-only Customer Portal administration. The browser walkthrough also covers the original credit application, Muse review and approval, manufacturer booking/BOL creation, and Muse booking confirmation.

Live Muse pricing and dispatch APIs remain unconnected; Muse's existing rate-entry and booking-queue workflows are unchanged.
