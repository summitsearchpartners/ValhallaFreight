# Valhalla Freight v0.5.2 — Structured Address Autofill Fix

## Fix
Corrects a state update ordering regression introduced during the shared Quote-to-Shipment workflow work.

When a Google Places suggestion was selected, the component correctly parsed the street, city, state, ZIP, and country. However, it then fired a second street-only value update after the structured address callback. In React, that second update used the previous address object and could overwrite city/state/ZIP with blank values.

The shared `AddressField` now updates the visible street value first and commits the structured address last, making the complete Google-selected address the final source of truth.

## Affected workflows
- Quote Studio Origin
- Quote Studio Destination
- Direct Create Shipment Origin
- Direct Create Shipment Destination
- Any future screen using the shared address component

No database changes are required.
