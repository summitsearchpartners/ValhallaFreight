# Valhalla Freight v0.8.0 — Carrier Integration Framework

## Purpose
v0.8.0 introduces Valhalla Freight's normalized carrier connectivity layer and the first complete carrier adapter scaffold: Dayton Freight Lines (SCAC DAFG).

## Architecture
Core TMS workflows call Valhalla interfaces. Carrier-specific request/response mapping is isolated under `backend/app/integrations/carriers/<carrier>/`.

Dayton modules include authentication/client handling, rating, pickup, tracking, eBOL/PDF BOL, document imaging, accessorial mapping, and normalized event/rate models.

## Dayton credentials
Set these only in the local/production environment, never in Git:

- `DAYTON_API_BASE_URL=https://api.daytonfreight.com`
- `DAYTON_API_USERNAME=`
- `DAYTON_API_PASSWORD=`
- `DAYTON_API_ACCOUNT=`

Dayton Basic Authentication uses the web username/password. Valhalla truncates the username to the first 10 characters for API auth to match Dayton's published guidance.

## Quote Studio
Dayton appears as a carrier in Carrier 360. When Dayton credentials are configured, Quote Studio attempts a live Dayton `/api/Rates` call and normalizes the returned cost, fuel, accessorials, transit days, movement type and carrier quote id. If Dayton is not configured, the application remains usable and marks that result as SIMULATED.

## Integration Hub
The Dayton adapter panel provides:
- credential readiness without exposing secrets
- connection/authentication test
- live rate workbench
- tracking workbench
- safe pickup TESTING call
- supported capability inventory

## OpenAPI import
Integration Hub can import a JSON OpenAPI/Swagger specification. Valhalla registers the provider, counts/tag-groups endpoints, and records capabilities. This accelerates onboarding but does not pretend carrier-specific normalization can be safely auto-generated.

## Future carrier pattern
Add each carrier as its own adapter under `backend/app/integrations/carriers/` and register its SCAC in the carrier registry. Core Quote/Shipment code must not contain carrier-specific endpoint details.
