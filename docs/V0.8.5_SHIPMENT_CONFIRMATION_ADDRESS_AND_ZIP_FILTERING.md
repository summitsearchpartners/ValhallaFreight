# Valhalla Freight v0.8.5 — Shipment Confirmation Address & Rated ZIP Filtering

## Changes

1. Google Places selections now populate Street, City, State, ZIP, and Country in one atomic structured-address update.
2. The shared address widget is initialized once and uses callback refs so React re-renders while typing do not destroy/recreate the Google autocomplete listener.
3. Quote-to-shipment saved-location dropdowns are filtered to the rated Origin ZIP and Destination ZIP respectively.
4. Shipment-confirmation ZIP inputs are read-only when tied to a rated quote. A different ZIP requires returning to Quote Studio and re-rating.
5. Existing approval-time ZIP validation remains in place as a backend/workflow safety check.
