# Valhalla Freight v0.5.5 — Login Readability

This release scales the existing Valhalla Freight login experience for large desktop displays without changing the established visual design.

## Changes
- Enlarged Valhalla Freight logo and product wordmark.
- Enlarged hero badge, headline, description, benefit cards, and footer copy.
- Enlarged Welcome Back card, labels, inputs, password controls, submit button, and security copy.
- Added desktop and short-viewport responsive sizing so the larger layout remains usable across common screen sizes.
- Preserved the existing split-screen Valhalla Freight branding and authentication behavior.
