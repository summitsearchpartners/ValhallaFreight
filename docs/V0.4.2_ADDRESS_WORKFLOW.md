# Valhalla Freight v0.4.2 — Address Workflow

## Changes

- Removed the visible Smart Address Lookup panel from Customer 360.
- Address autocomplete is now built directly into street-address fields.
- Added the same reusable address field to Create Customer and Add Customer Location.
- Selecting an address automatically fills City, State, ZIP and Country.
- Create Customer now stores the customer's primary/billing address in the CustomerProfile billing_address structure.
- If Google Places is not configured, the same address fields remain fully usable for manual entry with no configuration warning shown to users.

## Architecture

Address behavior is isolated into:

- `frontend/src/features/customers/components/AddressField.tsx`
- `frontend/src/features/customers/address/googlePlaces.ts`

The component uses Google's Places Autocomplete Data API so Valhalla Freight can retain its own form styling while presenting address predictions under the actual street-address field.

## Local Google Places configuration

Create or update the root `.env` file:

```env
VITE_GOOGLE_MAPS_API_KEY=YOUR_KEY_HERE
```

The key is passed to the frontend container by `docker-compose.yml`.
