# Valhalla Freight v0.8.6 — Google Verified Address Autocomplete Repair

Shipment Confirmation now uses Google Places API (New) `AutocompleteSuggestion.fetchAutocompleteSuggestions` and renders suggestions inside the Valhalla Freight UI. Selecting a verified address populates street, city, and state while the quoted ZIP remains locked to the Rated Lane. Saved Customer 360 locations continue to be filtered to the corresponding rated ZIP.
