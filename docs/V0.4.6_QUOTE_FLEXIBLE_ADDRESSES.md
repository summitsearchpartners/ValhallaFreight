# Valhalla Freight v0.4.6 — Flexible Quote Addresses

Quote Studio saved customer locations are now optional shortcuts instead of an address-entry mode.

- Origin and Destination address fields are always editable.
- Selecting a saved location prefills the normal address fields.
- Typing into a prefilled address immediately clears the saved-location selection and enables Google Places suggestions.
- Users can therefore use a saved customer location or enter any verified one-off address without changing modes.
