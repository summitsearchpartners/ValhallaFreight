# Valhalla Freight v0.7.8 — Quote Confirmation Google Autocomplete

This release replaces the custom prediction list in the shared address field with Google's native Places Autocomplete widget. The native suggestion container is mounted outside the Quote Detail sidebar, preventing clipping/stacking issues that caused Ship From / Ship To suggestions to disappear.

## Behavior
- Type 3+ characters or any normal street-address prefix in Ship From / Ship To.
- Google suggestions render above the shipment-confirmation workspace.
- Selecting a suggestion fills street, city, state, ZIP, and country.
- The fix is shared by Customer 360, shipment creation, and quote-to-shipment confirmation.

## Google requirements
The existing browser API key must allow localhost during development and have Maps JavaScript API plus Places API enabled.
