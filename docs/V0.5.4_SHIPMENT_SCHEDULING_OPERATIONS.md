# Valhalla Freight v0.5.4 — Shipment Scheduling & Operational Editing

This release adds customer-required pickup/delivery scheduling to Quote Studio and Direct Shipment creation, then carries those commitments into the Shipment Control Tower.

## Quote / booking schedule
- Requested pickup date & time (origin-local)
- Required delivery date & time (destination-local)
- Schedule persists on the quote and is carried into the approved shipment
- Carrier ETA remains a separate operational estimate based on transit days

## Shipment Control Tower editing
Shipment records can now be edited after booking for:
- BOL number
- PRO number
- Scheduled pickup
- Required delivery
- Actual pickup
- Actual delivery
- Operational status

Recording actual pickup or delivery also creates a manual tracking event. Recording actual delivery marks the shipment Delivered.

## On-time delivery KPI
The dashboard now evaluates actual delivery against the customer-required delivery timestamp when available. Older records without a customer-required timestamp continue to fall back to the carrier ETA date.

## Database compatibility
Startup applies idempotent `ADD COLUMN IF NOT EXISTS` upgrades for the new scheduling fields so existing local PostgreSQL data does not need to be wiped.
