# Valhalla Freight v0.12.9 — Account Directory & Popups

## Changes

Open **Administration → Users & Company Access** as a Valhalla Freight Admin.

- **Companies:** opens a searchable company directory. Search by name or company code, then click a company to filter its accounts in the main directory. The company dropdown and directory heading show the selection. Each company popup row includes total and active account counts.
- **Valhalla Admins:** filters the directory to active super-user accounts, matching the summary count.
- **Recently seen:** filters accounts seen in the previous two minutes, matching the summary count. The filter rolls forward automatically and can be cleared with its chip.
- **Total accounts:** resets the directory to all accounts. **Clear filters** also resets every filter.
- **Account names:** click a name to open a new Account Overview popup with name/email, role, company/portal, status, last login and last seen. Edit, Activity and Remove are now inside this popup; the table's Actions column has been removed.
- **Edit account:** opens a styled popup. Saving returns to the updated account overview. Role, company, enabled status and password reset continue using the existing server permission checks.
- **Activity:** opens a readable activity timeline with status, timestamps, request paths, expandable event details and older-history loading. A back button returns to the account overview.
- **Remove:** opens a matching confirmation popup with Keep account and Remove account controls. Canceling sends no removal request. Your own super-user account remains protected.
- **Add user/Add company:** use the same popup design. Creating a company filters the directory to that new company so accounts can be added to it.

Popups support Escape, keyboard focus trapping/restoration, background scroll locking, responsive layouts and reduced-motion preferences. Account searches, role selectors, company assignments and account permissions are retained.

- Backend regression suite: **16 passed** in isolated SQLite databases.
- Headless Chromium UI checks passed using API fixtures: company popup search/selection, summary-card filters/counts, clickable account names, edit/save, activity/back, styled removal/cancel/confirmation, Escape/focus restoration, responsive popup sizing and no JavaScript exceptions. These UI checks used mocked API responses; the backend suite separately exercised the real account and permission routes.
- Account directory, detail and edit popup layouts were visually inspected.
- Existing freight, role enforcement, PostgreSQL schema updates, Compose settings and document workflows remain intact. Backend business logic is unchanged in this release; only its reported version changed.

Docker/PostgreSQL container startup, live carrier integrations and final end-to-end acceptance against your local database still need local testing.

## Local upgrade

Keep your current `.env`, project directory and Compose project name. Extract this complete project into your existing ValhallaFreight directory, then run:

```powershell
docker compose up -d --build
docker compose ps
docker compose logs --tail=100 backend
```

Open http://localhost:5173. No volume deletion, database reset or new schema migration is required for this UI update. The previous non-destructive migrations remain included.
