# Valhalla Freight v0.8.1 — Integration Hub Production UX

This release makes the Integration Hub controls explicit and production-usable.

## Open adapter / Manage
Opens the carrier-specific control room. For Dayton this exposes adapter status, environment, customer account, terms, direct-only preference, backend credential status, supported capabilities, connection test, rate test, tracking test, and safe TESTING pickup.

## Import OpenAPI
Opens a functional file picker for Swagger/OpenAPI JSON. Valhalla analyzes the specification and registers an integration candidate, then shows the discovered API operation/capability summary. It intentionally does not auto-generate carrier-specific freight mappings or credentials.

## Dayton Freight quick action
The Dayton Freight button remains in the Integration Hub header because Dayton is the first direct carrier adapter. It is a shortcut to the same production adapter management screen as Open adapter / Manage.

## Status language
Adapter configured means the integration code/settings are installed. Live ready means provider credentials are configured and a real authentication test can succeed.
