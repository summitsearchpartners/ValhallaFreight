# Valhalla Freight v0.9.0 — Automatic Shipment Setup Workflow

When an approved quote is converted into a shipment, Valhalla now opens the newly created Shipment Control Tower record with the shipment setup modal already active. This removes the extra manual step of opening the shipment and clicking Edit.

## Workflow

Quote Record → Approve, build BOL & create shipment → Shipment created / 8-digit BOL assigned → Shipment Control Tower opens → Complete shipment setup modal opens automatically.

The setup form uses the existing shipment edit workflow and supports PRO, PO/customer reference, package count/type, NMFC, commodity description, hazmat emergency information, declared value, scheduled/actual service timestamps, and shipment status. The BOL remains system-assigned and immutable.

The `setup=1` route parameter is removed after saving or choosing Finish later so refreshing the shipment later does not repeatedly reopen the form.
