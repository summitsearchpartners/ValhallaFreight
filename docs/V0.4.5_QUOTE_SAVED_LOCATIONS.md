# Valhalla Freight v0.4.5 — Quote Studio Saved Customer Locations

Quote Studio now connects directly to Customer 360 locations.

## Workflow
- Selecting a customer loads that customer's active saved locations.
- Origin and Destination each provide a saved-location selector.
- Selecting a saved location fills street, city, state, ZIP, and country immediately.
- Users can still choose **Search a different address** and use the shared Google-powered verified address field.
- Changing the customer clears the prior lane addresses to prevent accidental cross-customer quoting.

## Architecture
Quote Studio consumes the existing Customer 360 API and shared address components rather than duplicating customer or Google Places logic.
