# Valhalla Freight v0.7.1 — Carrier Compliance Document Uploads

Carrier 360 compliance requirements now store actual uploaded documents instead of requiring external document URLs.

## Supported files
PDF, DOC, DOCX, JPG/JPEG, and PNG. The default upload limit is 15 MB and can be configured with `MAX_COMPLIANCE_DOCUMENT_MB`.

## Storage architecture
Development deployments persist document binaries in the Docker volume `valhalla_freight_documents` mounted at `/app/storage`. PostgreSQL stores compliance metadata and a version history, not document binary blobs. This boundary is intentionally compatible with a future S3/object-storage adapter.

## Version history
Replacing a compliance document creates a new `carrier_compliance_document_versions` record and keeps prior versions for audit history. The current compliance record points to the latest document metadata.

## User workflow
Carrier 360 → Compliance → Add/Edit requirement → drag-and-drop or browse for a file → Save. Existing documents expose View, Download, and Replace actions directly on the compliance card.
