# Valhalla Freight v0.13.0 — My Profile & System Settings

## My Profile

Company name and logo now live in **My Profile → Company identity**, alongside your personal information and account security. Upload/remove a PNG/JPEG logo and save the company name there. Company branding remains shared across authorized users in that manufacturer workspace. Manufacturer Admins and Valhalla Admins can edit it; regular Manufacturers see the shared branding as read-only.

Personal information has its own Save profile action. Password changes open a dedicated security popup. Valhalla Admins can select another company workspace to manage its branding without changing their own display name or password. Saving branding refreshes the sidebar immediately; other sessions refresh as before.

## System Settings

**Pricing Engine visibility** stays here as a separate company-wide setting. The control remains restricted to Manufacturer Admins or a Valhalla Admin managing that company. Valhalla Admins always retain their super-user Pricing Engine access. Branding and visibility saves use separate field-specific endpoints, so changing one does not overwrite the other.

Personal display preferences:

| Preference | Options |
| --- | --- |
| Color theme | Light, Dark, or System (follows operating-system changes) |
| Display density | Comfortable or Compact |
| Clock format | 12-hour AM/PM or 24-hour military time |
| Date format | MM/DD/YYYY, DD/MM/YYYY, YYYY-MM-DD |
| Display timezone | Device timezone, common US zones, UTC and selected international zones |
| Seconds | Show or hide in clocks and timestamp displays |
| Header clock | Show or hide the workspace clock |

The screen includes a date/time preview. **Save display preferences** applies and persists your choices. **Restore defaults** resets the draft; save to apply those defaults.

Display preferences are stored against the authenticated user, separately from company settings. They follow the account across sign-ins and devices and do not affect another user in the same company. Selecting a company as a super user does not redirect personal preferences to that company's users.

Dark mode applies to existing workspace surfaces, controls and popups, as well as the redesigned profile/settings screens. Compact density reduces table-row and navigation spacing. Common date/time displays—including account activity, notifications, shipment details and customer portal timestamps—use the preference-aware formatter. Calendar-only dates remain calendar dates. Offset-free appointment values retain the existing local interpretation; explicit timezone offsets remain respected. Stored shipment dates, appointment inputs and calendar scheduling logic are unchanged. BOL/label printing retains its existing document styling and formatting.

## Database and permissions

A new additive `user_display_preferences` table is created at startup using the existing SQLAlchemy metadata workflow. Existing PostgreSQL records, migration statements, shared company settings and named Docker volumes are retained. No reset is required. Removing a login also removes its personal preference row while retaining its historical activity.

New endpoints:

- `GET /workspace/preferences` and `PUT /workspace/preferences`: authenticated user's preferences only; invalid options/timezones and extra ownership fields are rejected.
- `PATCH /workspace/branding`: authorized company branding fields only.
- `PATCH /workspace/pricing`: authorized company Pricing Engine visibility only.

The previous workspace settings endpoint remains compatible. Shared edits retain existing server role/company checks. Ordinary manufacturer users can save their own display preferences but cannot change shared branding or Pricing Engine access.

## Local Docker upgrade

Extract into your existing ValhallaFreight project directory, retain your current `.env`, and use the same Compose project name to retain the database/document volumes. A backup is recommended before any software upgrade:

```powershell
docker compose exec -T db pg_dump -U valhalla_freight -d valhalla_freight -Fc -f /tmp/valhalla-before-v0.13.0.dump
docker compose cp db:/tmp/valhalla-before-v0.13.0.dump ./valhalla-before-v0.13.0.dump
docker compose up -d --build
docker compose ps
docker compose logs --tail=100 backend
```

Open http://localhost:5173. Verify company branding in My Profile, then save your display preferences and company Pricing Engine visibility in System Settings. Sign out/in or restart to confirm persistence. Also perform your usual multi-class quote → verified addresses → shipment → printed BOL check.
