# Valhalla Freight v0.4.4 — Quote Studio Smart Lane Addresses

## Changes
- Origin and Destination street-address fields now use the same Google Places autocomplete used by Customer 360.
- Selecting a Google suggestion automatically fills City, State, ZIP, and Country before rating.
- Removed hard-coded sample origin/destination addresses to reduce accidental quoting against stale data.
- Refactored Google Places and AddressField into `frontend/src/shared/address/` so all future address inputs can use one implementation.
- Quote Studio moved behind a feature module (`frontend/src/features/quotes/QuoteStudioPage.tsx`) while the legacy page path remains a tiny compatibility re-export.

## Goal
Use one smart address experience throughout Valhalla Freight to reduce keystrokes, malformed locations, and shipment/rating errors.
