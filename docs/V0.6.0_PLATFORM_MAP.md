## Operating lifecycle
Quote → Sell → Book → Source → Dispatch → Track → Deliver → Audit → Invoice → Pay → Analyze → Optimize

- Command Center
- Quote Studio / Quote Bucket / Quote Detail
- Shipment Control Tower / Direct Shipment Creation
- Visibility Center
- Automation Center

### Network

### Finance & Risk

- Claims Center

### Intelligence
- Valhalla Freight Intelligence
- Network Analytics
- Prospect Analysis

### Administration
- Integration Hub
- Customer Portal Administration

## Integration policy
Provider-specific payloads and credentials belong behind adapters. Core quote, shipment, carrier, finance and visibility logic must use Valhalla Freight normalized models.

## Production boundary
The Integration Hub lists supported adapter targets and provides health/configuration workflow. Live calls to external providers require provider contracts, API credentials, mapping, test certification, error handling and production enablement.
