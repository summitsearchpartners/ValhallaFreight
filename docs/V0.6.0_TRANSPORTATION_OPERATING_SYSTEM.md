# Valhalla Freight v0.6.0 — Transportation Operating System Expansion

This release expands Valhalla Freight beyond the original LTL workflow into a modular brokerage operating platform while preserving the working Quote Studio, Customer 360, Shipment Control Tower, Command Center, authentication, Google address intelligence, and PostgreSQL data model.

## New operational domains

- Carrier 360 — carrier master, authority, compliance, contacts, terminals, performance and shipment history.
- Capacity Center — internal capacity loads, target buy, market guidance, provider-posting adapter hooks and carrier offers.
- Visibility Center — shipment milestone and customer-required-delivery visibility queue.
- Finance Center — carrier bill audit queue, quote-vs-invoice variance, approve/dispute workflow and final carrier cost updates.
- Claims Center — shipment-linked claims records and resolution workflow.
- Valhalla Freight Intelligence — database-derived operational insights and cross-domain exception routing.
- Integration Hub — provider/category registry for carrier connectivity, rate intelligence, load boards, DFM, visibility, onboarding, accounting, payments, claims, CRM and routing.
- Customer Portal Administration — product foundation for permission-based customer quoting, booking, tracking, documents and invoices using the same APIs.

## Important integration boundary

The provider adapters are product-ready configuration surfaces, not live vendor contracts. External services such as DAT, Truckstop, project44, MacroPoint, QuickBooks, Highway, RMIS, RoadSync and others require customer/vendor credentials, subscriptions, API agreements and provider-specific implementation before production calls can be enabled.

Valhalla Freight deliberately keeps those provider adapters outside core business logic so vendors can be added or replaced without rewriting quote, shipment, carrier, finance or visibility workflows.
