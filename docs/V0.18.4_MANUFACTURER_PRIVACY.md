# v0.18.4 Manufacturer commercial privacy

Manufacturer and Manufacturer Admin accounts see their quoted transportation price, without carrier buy cost, gross profit, margin, or broker markup. The change applies to new/saved quotes, booking summaries, shipment details/quick views, dashboards, analytics, and customer profiles. Manufacturer support sessions use the same privacy policy.

The backend removes private commercial fields from customer-facing JSON responses. Manufacturers cannot submit broker pricing overrides or read internal pricing rules/carrier payables. The company Pricing Engine visibility setting still controls access to a customer-safe pricing workspace. Finance presents customer invoices. Broker, Broker Admin, Muse rate management, and Valhalla Super Admin financial tools retain their financial information.

## Local Docker testing

Keep your existing installation directory, compose project name, environment configuration, and volumes. Back up your database before replacing application files. Copy this release over the existing project, then run:

```sh
docker compose up -d --build
```

Open http://localhost:5173. Existing logins remain valid. No database schema changes or new migrations are required. Do not delete existing volumes or run reset scripts.
