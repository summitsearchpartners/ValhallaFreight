# Valhalla Freight v0.13.1 — Branding & Single-Page Saves

## Branding and Command Center

- Uploaded company logos now use rectangular, aspect-preserving frames in the sidebar and top-right account control. The full image is contained inside the frame instead of being cropped into a circle.
- Command Center displays the company logo before **Good Morning, [Company Name].** The greeting no longer contains a hard-coded person's name.
- The sidebar and Command Center share the same company branding state. Saved branding refreshes both immediately; existing periodic/focus refresh behavior remains available for other sessions.
- Valhalla Freight's Powered by branding now sits immediately above **System healthy**, inside a pinned sidebar footer. Long navigation lists scroll independently so the footer stays available. Collapsed/mobile layouts retain complete, uncropped logo images.
- When no custom company logo exists, the normal Valhalla logo/initials fallbacks remain available.

## One Save button on each page

**My Profile** has one **Save changes** button after all sections. It saves the user's display name and any authorized company name/logo changes in one database transaction. Regular manufacturer users can save their personal name without submitting read-only company branding. Password updates remain inside their separate security popup; opening that popup does not submit the profile page.

**System Settings** has one **Save changes** button after all sections. It saves personal appearance/date/time preferences and any authorized company Pricing Engine visibility change together. Regular users save personal preferences without submitting a company-access edit. A Valhalla Admin can still select a company workspace while personal preferences remain attached to the admin account.

Invalid or unauthorized combined submissions do not leave partially saved profile names/preferences. Existing individual save endpoints remain compatible for earlier clients.

New page-save endpoints:

- `PUT /workspace/profile-page`
- `PUT /workspace/settings-page`

No schema migration or reset is introduced in this release. PostgreSQL data, current migrations, role checks, company isolation, carrier API setup and document volumes remain intact.

## Local upgrade

Extract into the existing ValhallaFreight directory and retain your current `.env` and Compose project name. Run:

```powershell
docker compose up -d --build
docker compose ps
docker compose logs --tail=100 backend
```

Open http://localhost:5173. Verify your uploaded logo in the sidebar/header and Command Center, then edit multiple sections and save once on each page. Existing freight, account assignments, company branding and display preferences should remain present. No volume deletion or database reset is needed.
