# Valhalla Freight v0.2.1 Login Fix

Fixes the local development login introduced in v0.2:

- Allows the seeded `admin@valhallafreight.local` development login identifier.
- Pins `bcrypt==4.0.1` for compatibility with Passlib 1.7.4, eliminating the bcrypt `__about__` startup warning.
- Converts FastAPI validation detail arrays into readable frontend error messages instead of `[object Object]`.

Rebuild the backend image after applying this patch:

```powershell
docker compose down
docker compose up --build
```
