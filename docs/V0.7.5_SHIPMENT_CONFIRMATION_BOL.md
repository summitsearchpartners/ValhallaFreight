# Valhalla Freight v0.7.5 — Shipment Confirmation Address & Immutable BOL

## Shipment confirmation address lookup
The shared Google Places address component no longer limits predictions to only `street_address`. This improves matching for rural routes, numbered roads, premises, and industrial facilities. Selecting a prediction still resolves structured street, city, state, ZIP, and country values. The shipment-confirmation card also explicitly permits the suggestion overlay to render above surrounding content.

## BOL numbering
Valhalla-created shipments receive a numeric BOL once the shipment has an internal database id. The generated value begins at `10000001` and is checked for conflicts with existing/imported BOL values. No `VFBOL-` prefix is used.

## Immutability
The BOL is no longer accepted by the shipment-edit API and is no longer editable in the Edit Shipment modal. Operations can still edit the carrier PRO, customer references, commodity/NMFC/hazmat data, and operational timestamps.
