# Valhalla Freight v0.9.3 — Free-Entry Freight Class

Quote Studio no longer limits freight class to a dropdown. The Class field is a required free-entry text field with decimal keyboard support.

Examples:
- 50
- 70
- 77.5
- 92.5
- 100
- 125
- 500

The backend already stores `freight_class` as a string, so no database migration is required. Carrier adapters may validate or normalize the value as required by each carrier API.
