# Valhalla Freight v0.7.7 — Quote Confirmation Address Autocomplete Fix

This release hardens the shared Google Places address service used during quote-to-shipment confirmation.

## Fixes
- Restores autocomplete suggestions in the Quote Bucket shipment-confirmation Ship From / Ship To fields.
- Uses Places API (New) when available and automatically falls back to the legacy Places prediction/details services when needed.
- Supports both new (`longText`, `shortText`) and legacy (`long_name`, `short_name`) Google address component formats.
- Keeps City, State, ZIP and Country autofill after selecting a verified address.
- Explicitly loads the Google `places` library for compatibility.

The fix lives in the shared address module, so Quote Studio, shipment confirmation, direct shipment creation and other Valhalla address workflows use the same hardened implementation.
