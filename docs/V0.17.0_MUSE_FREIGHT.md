# v0.17.0 — Muse Freight preview

- “Powered by” Muse Freight branding is shown on sign-in, in the workspace sidebar, and in the customer portal. The bundled mark is the Muse logo served by its [customer portal](https://musefreight.taicloud.net/).
- Quote Studio and saved unbooked LTL quotes show a **Muse Rate** preview beside the existing options. The preview never supplies a carrier ID, dollar amount or transit time, and cannot be selected as a billable rate, emailed as a quote, or booked. Direct, configured and simulated carrier options still use the existing rating flow.
- The preview lists Muse’s LTL, Truckload, Intermodal, Expedited and Refrigerated services. The LTL quote form still rates LTL only; the other services are listed for reference.
- **Review preview** opens a dialog with the [Muse credit application](https://cdntms.taicloud.net/tms/Credit_Application.pdf) when the customer first uses the preview or has no verified account. The link opens in another tab. Valhalla Freight does not collect or submit the application. Opening the PDF does not verify an account.
- A Valhalla Freight Admin can set a customer's verified status in **Customers → customer → Commercial → Muse Freight account** after Muse confirms the account. Verification and first preview are shared by all authorized users quoting for that customer. Verification can be removed if needed.

## Upgrade and test

From the directory used by your existing Compose project, replace the application source with this release and keep your existing `.env`, Compose project name and PostgreSQL volume. Then run:

```sh
docker compose up -d --build
docker compose ps
```

Keep using the existing PostgreSQL volume. Startup creates the new `muse_accounts` table through the application metadata, with no change to existing rows or migrations.

1. Check the logo on sign-in and in the sidebar.
2. As a manufacturer user, rate an LTL shipment with a valid ZIP pair and freight line. Confirm your current carrier options appear alongside **Muse Rate**, and open **Review preview**.
3. For an unverified customer, confirm the credit application opens in a separate tab. Close it and confirm a normal carrier option can still be selected and converted to a shipment.
4. As a Valhalla Freight Admin, save verification from that customer's **Commercial** tab. Reopen the preview for the same customer and confirm it shows the verified state.

## Live integration

Before enabling live Muse rates, obtain Muse’s carrier/service catalog, production or sandbox credentials, account identifiers, quote and booking APIs, and lane/service eligibility rules. The normalized rate shape accepts a `provider` identifier; `muse_freight` displays a **Muse Rate** badge alongside the actual carrier. Future live work must verify customer eligibility server-side, use a unique offer identifier when a carrier appears through multiple sources, and route the chosen offer to the correct provider at booking. No live Muse credentials, requests, or dispatches are in this release.
