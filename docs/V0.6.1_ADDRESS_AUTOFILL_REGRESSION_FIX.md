# Valhalla Freight v0.6.1 — Address Autofill Regression Fix

## Fix
Corrected the shared Google Places address selection callback order. The street field is now updated first and the complete structured address is committed last, preventing stale parent state from clearing City, State, ZIP, and Country after a Google address selection.

## Affected workflows
- Quote Studio origin and destination
- Direct Create Shipment origin and destination
- Any future workflow using `frontend/src/shared/address/AddressField.tsx`

No database changes are required.
