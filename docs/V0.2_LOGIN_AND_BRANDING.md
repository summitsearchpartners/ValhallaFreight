# Valhalla Freight v0.2 - Login & Branding

This release introduces the first authenticated application shell and the Valhalla Freight visual identity.

## Included
- Two-panel professional Valhalla Freight login experience
- Valhalla Freight logo on the login screen and application sidebar
- JWT login/session flow
- Seeded local administrator account
- Protected operational API routes
- Authenticated `/api/v1/auth/me` session restoration
- Sign-out control
- Visible product renaming from FreightForge to Valhalla Freight

## Local development credentials
- Email: `admin@valhallafreight.local`
- Password: `Valhalla123!`

These credentials are development-only. Before any shared or AWS deployment, set `DEFAULT_ADMIN_PASSWORD` and `JWT_SECRET_KEY` using environment/secret management and remove default credentials from the deployment environment.

## Existing database compatibility
The PostgreSQL database/volume identifiers remain named `freightforge` internally in v0.2 so an existing v0.1 local database can be upgraded without destructive volume migration. Product-facing branding is Valhalla Freight. Internal database identifiers can be renamed later through a controlled migration.
