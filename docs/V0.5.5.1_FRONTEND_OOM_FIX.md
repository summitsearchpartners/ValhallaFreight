# Valhalla Freight v0.5.5.1 — Frontend OOM Fix

Fixes a packaging error that caused `frontend/src/styles.css` to grow to roughly 405 MB by repeating the login CSS many times. Vite exhausted the Node.js heap while parsing the oversized stylesheet.

Changes:
- Restored the clean v0.5.4 stylesheet baseline.
- Applied the v0.5.5 login readability overrides exactly once.
- Added `frontend/.dockerignore` to exclude Node build/cache artifacts from Docker build context.
- No backend or database changes.
