# v0.17.1 — See the Muse Freight price before selecting it

A Muse Rate displays the carrier and exact USD customer price entered by a Valhalla Freight Admin using the quote supplied by Muse. The application does not have live Muse credentials or a Muse tariff and does not invent a price. Until the admin adds a price, the row says that the price is pending and offers no Select action. A Muse rate is tied to one saved quote and never replaces company carrier options or selects one of them.

## Try it in Docker

Keep your existing project directory, Compose project name, `.env`, and PostgreSQL volume. Update the application source, then run:

```sh
docker compose up -d --build
```

Open http://localhost:5173. Startup creates the new `muse_quote_rates` table alongside the existing tables. The Compose file and existing migration script are unchanged.

1. As a manufacturer user, rate an LTL shipment in **Quote Studio**. Keep the quote number, or click **Open saved quote** beside the Muse row.
2. As a Valhalla Freight Admin, open that quote from **Quote Bucket**. In **Carrier options → Muse Rate**, click **Add Muse rate**, enter the quoted carrier and USD customer price, and save. For a local test you can enter a test carrier and price. Enter a quote supplied by Muse for actual use.
3. Back in the original Quote Studio results, click **Refresh Muse rate**, or reopen the saved quote. The carrier and price now appear next to **Select**. Other carrier prices and controls remain available.
4. Click **Select**. An unverified customer sees the carrier, price, and **Open credit application**, which opens the PDF in a separate tab. A verified customer sees the same rate with booking instructions. The app does not submit the form, verify credit, or book a Muse shipment.
5. An admin can edit or withdraw the rate from the saved quote. If a quote expires, rate a new one. If the price changed after the customer opened the quote, selection asks them to refresh before proceeding.

To verify a confirmed Muse account, go to **Customers → customer → Commercial → Muse Freight account** as a Valhalla Freight Admin.
