# v0.12.3 — Live Direct/Indirect Qualification + Density Guard UI

## Carrier API movement qualification
- Live carrier rate responses are now the source of truth for whether a lane is Direct or Indirect.
- Dayton's `movementType` response is normalized to Direct/Indirect; partner/interline service is also recognized from carrier-provided partner fields when needed.
- Carrier 360 Direct Service Only rules now evaluate the returned live quote. An Indirect or unverified/Unknown live result is suppressed for a Direct Only lane.
- Carrier 360 lane rules no longer guess service coverage from geography.
- Quote Studio displays the live API movement result on carrier rates so brokers can see DIRECT SERVICE or INDIRECT SERVICE.
- Simulated rates are never treated as verified direct service.

## Quote Studio density guard
- LTL Density Guard is now its own full card beneath Pricing Control.
- Each handling unit has a larger class result with Qty, weight, and dimensions visible for review.
- The guard continues to auto-populate Freight Details class while leaving Freight Details editable for an actual NMFC override.
