# Valhalla Freight v0.8.4 — Requested Pickup Date

Quote Studio now captures an optional customer-requested pickup date instead of a required delivery date.

## Data flow

`Quote Studio -> requested_pickup_at -> Quote Record -> Shipment Confirmation -> scheduled_pickup_at`

This keeps the customer request distinct from the shipment's `actual_pickup_at` and `delivered_at` operational timestamps. The existing `requested_delivery_at` field remains available at the shipment level for future must-arrive-by commitments but is no longer populated from Quote Studio by this field.
