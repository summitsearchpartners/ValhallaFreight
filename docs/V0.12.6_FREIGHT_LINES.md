# v0.12.6 freight line preservation hotfix

- Shipment confirmation shows each rated handling unit separately, with its own quantity, dimensions, weight and freight class.
- Aggregate package count is read-only, calculated from rated freight lines.
- Dayton live booking sends per-line pieces and package type rather than repeating total package count on every line.

This is a focused incremental fix. It does not complete account-wide manufacturer authorization, shared branding, or independent BOL PDF rendering validation.
