# Valhalla Freight 0.16.0 — Broker accounts

In **Administration → Users & Company Access**, a Valhalla Freight Admin can create or edit an account, choose **Broker Admin** or **Broker**, and select the parent company under **Company / Portal**. Both roles use the normal Valhalla Freight sign-in page.

| Access | Broker | Broker Admin |
| --- | --- | --- |
| Assigned company's operations, quotes, shipments, customers, capacity, finance, claims, and reports | Yes | Yes |
| Shared carrier directory and company carrier performance | View | View |
| Company-owned carrier administration | — | Yes |
| Company pricing | View if enabled | Manage |
| Company branding, Integration Hub, customer portal configuration, and integration retries | — | Yes |
| Users & Company Access and cross-company Portal Access | — | — |

Valhalla Freight Admin remains the platform Super Admin and manages account assignments and platform-wide records. Each broker account can work with its assigned company and that company's customer records. The shared carrier catalog is read-only in broker workspaces. Company-specific carrier and capacity records and freight email history are scoped to the assigned company.

The legacy Broker role no longer grants platform-wide access. Assign existing unlinked Broker accounts to a company before they use the workspace. No existing accounts are automatically reassigned.

## Install and test

Copy the updated project over your existing Valhalla Freight installation. Keep your existing environment configuration, Compose project name, and database/document volumes.

```powershell
docker compose up -d --build
docker compose ps
```

The backend adds company ownership columns and indexes at startup. It assigns existing quote and carrier-bill outbox records to a company where their source records identify one. Platform records with no known owner stay platform-only. Existing carrier records stay in the shared catalog. Existing capacity records linked to shipments follow the shipment's company. No tables or volumes need to be reset.

After upgrading, create one of each broker role under a test company. Sign in as each user, open Quote Studio and the quote bucket, and verify you see that company's freight. Broker Admin should also see Integration Hub and Customer Portal administration. Sign in as Valhalla Freight Admin to confirm Users & Company Access and Portal Access remain available.
