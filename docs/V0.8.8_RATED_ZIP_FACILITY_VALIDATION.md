# Valhalla Freight v0.8.8 — Rated ZIP Facility Validation

## Purpose
Prevent a shipment from being created when the actual Ship From or Ship To facility does not belong to the origin/destination ZIP used to obtain the quote.

## Behavior
- Saved Customer 360 locations remain filtered by rated ZIP.
- Google Places selections preserve the actual verified ZIP in `verified_postal_code`.
- The displayed ZIP remains locked to the rated lane.
- One-off addresses must be selected from Google suggestions before approval.
- If the verified facility ZIP differs from the rated ZIP, the approval button returns a clear re-rate error.
- Backend shipment booking performs the same validation, preventing API/UI bypass.

## Example
A quote rated `66061 -> 45414` cannot be approved with a Kansas City destination in ZIP `64114`, even if the visible destination ZIP field is locked to `45414`. The user must select a facility in `45414` or re-rate the shipment.
