# Valhalla Freight v0.11.4

## Optional quote markup defaults

Quote Studio no longer preloads a quote-specific markup value. The Flat and Margin amount field starts blank for every customer selection.

When the amount is blank, Quote Studio sends no quote-level pricing override (`quote_pricing_mode=null`, `quote_pricing_value=null`), so the normal customer/pricing-engine rules remain in control.

Entering a Flat or Margin value applies that override only to the current quote. The value remains internal and is folded into the customer sell price rather than shown as a separate line item.

Switching between Flat and Margin also clears the quote-specific value so a dollar amount cannot accidentally carry over as a percentage (or vice versa).
