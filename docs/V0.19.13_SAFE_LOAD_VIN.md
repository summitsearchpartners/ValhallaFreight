# v0.19.13 — Framed VIN photo and localized VIN reading

## Changes

- The phone now crops VIN photographs through the same real guide-to-image geometry used for ID photos. The accepted VIN image is the outlined strip, not the full camera image. The preview shows the exact cropped evidence before Accept; Retake and Cancel retain their existing behavior. Existing saved full-frame photos remain in custody unchanged.
- The VIN reader locates bright or dark printed text regions before single-line OCR. This helps isolate etched windshield text from the dashboard, glass and reflections. It tries rotated images, grayscale contrast enhancement and upsampling; whole-frame OCR remains a fallback when text localization yields no candidate.
- A complete standalone VIN line with OCR-added letter spacing can be normalized. The reader does not replace look-alike characters, fill missing characters, infer a VIN from the dispatcher assignment, or combine text across lines.
- Multiple differing candidates or unreadable text hold release. An extracted 17-character VIN still must exactly match the assigned truck VIN. Rejection notification, broker callback/release, ID renewal handling, encrypted evidence and custody receipts remain.

The supplied screenshot is a small preview of a full photo; the screenshot itself did not yield an unambiguous VIN in diagnosis. A human-readable preview is not proof that OCR recovered the exact characters. This update improves framing and reading but cannot guarantee every photo is readable. Check original camera photos on your phone. Avoid glare across the characters and fill the guide with the full VIN. Never release freight by substituting an expected value for unreadable evidence.

## Update the PC and phone

Preserve your existing .env, PostgreSQL and document volumes. Copy the ZIP's inner ValhallaFreight contents over C:\GitHub\ValhallaFreight. This is complete source, not a backup of your running database. No existing migrations are changed.

Stop the old Metro window with Ctrl+C, then rebuild:

```powershell
Set-Location C:\GitHub\ValhallaFreight
docker compose -p valhallafreight up -d --build
```

In a separate PowerShell window:

```powershell
Set-Location C:\GitHub\ValhallaFreight\safe-load-mobile
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-SafeLoad.ps1 -ComputerIP 192.168.1.195
```

Scan the NEW QR in Expo Go SDK58; verify **App v0.19.13**. TMS server URL remains http://192.168.1.195:8000 unless the PC's IP changed.
